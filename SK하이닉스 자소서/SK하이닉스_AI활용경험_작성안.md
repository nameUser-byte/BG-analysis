# SK하이닉스 AI 기반 문제 해결 경험 문항 작성안

---

## 헤더

**[기간]** 2026.08.12 ~ 2026.08.18  
**[경험]** AI 에이전트 기반 반도체 후공정 SAW 공정 SPC Out-of-Control 원인 분석 및 개선안 도출  
**[역할]** 가설 설계 및 AI와의 반복 검증 주도, 물리적 원인 해석 및 투 트랙(Two-track) 개선 전략 수립

---

## 본문

### ▮ 배경 및 문제 정의 (무엇을, 왜)

- 반도체 후공정 Sawing(SAW) 공정에서 SPC Out-of-Control(OOC) 비율 **6.83%** 발생, 수율 영향 및 설비 이상 여부 불명확
- 분석 대상 데이터: **20,000건 × 44개 변수** (Blade 마모도, 절삭 속도, 냉각수 유량, Xbar/Range 등) → Excel 단독 분석으로는 패턴 탐색 및 통계 검정 비현실적
- **2026.08.12~14(3일간)** 팀원들과 직접 수작업으로 분석을 시도하였으나, 다변수 상관관계 해석 및 통계 검정(VIF, 카이제곱, Cpk 산출 등) 구현에 한계에 봉착하여 명확한 원인 규명 미도달

> **→ AI 에이전트 없이 동일 수준의 분석을 수행할 경우 약 1주일 이상 소요 예상**

---

### ▮ AI 활용 방식 (어떻게, 왜 AI여야 했나)

**단순 질의응답이 아닌, 가설 → 통계 검증 → 결과 해석 → 재반박의 반복 구조로 활용**

1. **가설 제시 단계:** 분석 방향을 직접 설계하고 AI에게 구체적 질문을 통해 검증 요청
   - *예: "OOC 중 3시그마를 벗어나지 않은 비율이 82%인데, 이것이 숨겨진 기계적 변수가 있다는 증거가 될 수 있는지 통계적으로 검정하고 시각화해줘"*

2. **코드 자동 생성 및 실행 단계:** AI가 Python 코드(pandas, scipy, statsmodels, sklearn, seaborn)를 즉시 생성·실행하여 분석 결과 도출
   - VIF(분산팽창인수), 조건수, 카이제곱 검정, 다중 t-검정, 로지스틱 회귀, Random Forest + SHAP, Cpk 산출 등 20종 이상의 통계 기법 코드 자동화

3. **결과 반박 및 심층 탐색 단계:** AI의 해석에 물리적 관점에서 직접 반박하며 추가 분석 지시
   - *예: "마모율이 높아지면 속도를 낮추는 것이 정석인데 우리 데이터는 반대야. 이게 '천장 효과(Ceiling Effect)'를 만든 것이 아닌지 마모 구간별 속도 표준편차 변화를 뽑아봐"*
   - → 통계 검증 후 **Speed 표준편차: 1.31(정상 구간) → 0.99(마모율 100% 초과 구간)** 발견 (산포 역감소 = 통제 여력 상실 입증)

4. **결과물 자동 생성 단계:** 분석 결과를 바탕으로 HTML 종합 보고서, 19종의 시각화 그래프, 발표용 스토리보드까지 일괄 자동 생성 지시 및 완성

### ▮ 핵심 발견사항 및 수치화된 결과 (무엇을 밝혔나)

| 분석 항목 | 발견 내용 | 의미 |
|---|---|---|
| OOC 판정 구조 | OOC의 **82%**가 3σ 관리한계 내에서 발생 | 현 SPC 기준이 과민 설정(Over-control)이거나 미수집 기계적 변수 존재 |
| 파라미터 상관관계 | Blade Wear × Speed **r = 0.863** | 마모 진행 시 작업자가 임의로 속도를 높이는 비표준 보상 제어 패턴 규명 |
| Speed 천장 효과 | 마모 100% 초과 시 Speed 표준편차 **1.31 → 0.99** 급감 | 공정이 한계 속도(USL)에 고착되어 제어 여력 완전 상실 |
| Coolant 방치 | 전 마모 구간에서 냉각수 유량 **1.59 L/min 고정** | 마찰열 급증에도 열 방출 조치 부재 → 칩핑(Chipping) 위험 |
| 공정 능력 | Speed Cpk **0.587**, Coolant Cpk **0.611** (기준 1.33) | 두 핵심 파라미터 모두 공정 능력 기준 미달 |
| ML 예측 모델 | AUC = **0.51** (랜덤 예측 수준) | 실패가 아닌, 수집 변수에 OOC 원인이 없음을 통계적으로 증명 |
| BG 공정 독립성 | BG 불량 × SAW OOC 카이제곱 **p = 0.776** | 전 공정 전가 차단, SAW 공정 내부 기계적 문제로 원인 특정 |

### ▮ 결과물 및 기대 효과

**[정량적 성과]**
- 분석 완료 소요 시간: 예상 1주일 → **하루(8시간)로 단축 (약 80% 시간 절감)**
- 3일간 수작업으로 해결하지 못한 근본 원인 규명을 AI 활용으로 **당일 완성**
- 통계 기법 20종, 시각화 그래프 19종, HTML 보고서 1종 자동 생성

**[도출된 개선안 — 투 트랙(Two-track) 전략]**
- **[즉시 조치]** Blade 교체 기준 90%로 표준화 → Blade 100% 초과 운영 **898건(4.5%) 원천 차단**
- **[시스템 조치]** OOC 알람 기준 3σ 현실화 → Over-control 제거 및 생산성 저하 방지
- **[단기 조치]** Spindle Run-out 정기 측정 및 캘리브레이션 의무화
- **[장기 조치]** 마모 구간별 Speed/Coolant 연동 제어 SOP(표준작업절차) 문서화

### ▮ AI 활용에서 얻은 인사이트

- AI는 "도구"가 아니라 **"가설을 논리적으로 부딪혀 볼 수 있는 분석 파트너"**로 활용할 때 가장 강력함
- 도메인 지식(공정 물리 메커니즘, 반도체 절삭 원리)을 갖춘 사용자가 AI의 통계 처리 능력과 결합할 때 단순 AI 사용을 초월한 **"도메인+데이터 복합 분석"** 이 가능함
- 분석 결과의 타당성은 AI가 보장하지 않으며, **직접 가설을 세우고 반박하는 비판적 사고**가 AI 활용의 핵심 역량임을 확인
