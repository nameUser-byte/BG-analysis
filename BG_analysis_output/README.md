# BG (Back Grinding) 공정 불량 요인 종합 분석

본 디렉토리 및 상위 폴더의 파이썬 스크립트(`bg_comprehensive_analysis.py`)는 반도체 후공정 중 Back Grinding(BG) 공정에서 발생하는 불량의 근본 원인을 통계적, 기계학습적, 물리적 관점에서 종합적으로 분석하는 파이프라인입니다.

## 📊 분석 개요

1. **데이터셋**: `20000_BGTTV.xlsx` (총 20,000건의 합성/시뮬레이션 데이터, BG 불량 포함)
2. **분석 목표**: 
   - 기존 분석(PPTX) 주장의 타당성 검증 (Fact Check)
   - 통계적 공정능력(Cpk) 및 머신러닝 변수 중요도 평가
   - 시각화 및 다중공선성(VIF)을 통한 열화 패턴 파악
   - **물리적 도메인 지식 기반의 해결책(DOE) 도출**

## 🎯 핵심 결론 (Insights)

* **극저의 공정 능력**: 출하 규격(USL=3.0μm) 대비 산포 밀도를 볼 때, Cpk가 **0.15** 수준으로 목표치(1.33)에 한참 미달하는 극도로 불안정한 상태입니다.
* **불량의 주원인 (입고 TTV)**: Random Forest 분류 결과, 출하 불량을 유발하는 압도적인 요인(중요도 89%)은 앞단에서 유입된 **'입고 웨이퍼의 휨(TTV_Before)'** 상태입니다.
* **역상관성 메커니즘**: 연삭 후 Scratch는 크게 감소(2.93→1.24)했으나 Crack은 오히려 증가했습니다. 이는 얕은 기스를 깎아내는 Fine Grinding은 정상 작동 중이나, 초기 **Rough Grinding 단계에서 가해진 과도한 가공 압력(P)과 속도(V)가 깊은 SSD(Sub-Surface Damage)를 남겼음**을 의미합니다. 휜 웨이퍼(높은 TTV)일수록 이 데미지를 버티지 못하고 크랙으로 이어집니다.
* **프로젝트 방향성 제언**: 따라서 단순한 파라미터 튜닝이나 Fine Grinding 두께 상향이 아닌, **"입고 TTV 산포에 맞추어 Rough Grinding 단계의 압력(P) 및 속도(V)를 하향 최적화하는 제어 로직 수립"**이 본 분석 프로젝트의 최종 방향성입니다.

## 🛠 주요 파일 설명

- `../bg_comprehensive_analysis.py`: 데이터를 로드하고 통계/ML 분석을 수행한 뒤, SAW 리포트와 동일한 포맷의 HTML 리포트를 자동으로 생성하는 파이썬 스크립트입니다.
- `../bg_analysis_report.html`: 파이썬 스크립트가 뱉어내는 최종 결과물(정적 웹 리포트)입니다. 모든 차트가 Base64로 내장되어 단일 파일로 동작합니다.
- `SKILL.md`: 본 분석의 전체 파이프라인을 다른 AI 에이전트가 재현할 수 있도록 정리한 워크플로우 명세서입니다.

## 🚀 실행 방법
상위 디렉토리에서 아래 명령어를 실행하면 최신 데이터에 기반하여 리포트가 재생성됩니다.
```bash
python bg_comprehensive_analysis.py
```
생성 완료 후 브라우저에서 `bg_analysis_report.html`을 열어 확인하십시오.
